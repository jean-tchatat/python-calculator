# Python Calculator

A beginner-friendly Python calculator developed as part of my COSC 175 coursework at Towson University.

## Features

- Performs addition, subtraction, multiplication, and division.
- Allows users to select an operation through a numbered menu.
- Accepts numerical input from users.
- Handles division by zero and invalid menu selections.
- Includes an additional exercise for performing arithmetic calculations on two integers.

## Technologies Used

- Python 3
- Conditional statements (`if`, `elif`, `else`)
- User input and arithmetic operations
- Basic error handling

## How to Run

1. Install Python 3.
2. Download the Python file from this repository.
3. Open a terminal in the folder containing the file.
4. Run:

   `python calculator.py"`

5. Follow the instructions displayed in the terminal.

## What I Learned

This project helped me practice conditional statements, user input, arithmetic operations, and handling invalid selections. It also gave me experience organizing code into small, interactive programs.
